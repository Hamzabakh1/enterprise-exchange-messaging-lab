# Prerequisites

**DOCUMENTED ONLY.** Obtain licensed Exchange Server SE media, supported Windows Server OS, validated CPU/RAM/storage sizing, AD forest and DNS, network/firewall design, TLS certificate for actual namespaces, backup storage and mail-domain ownership. Confirm latest support matrix and build before installing. A fictional `.test` domain cannot be used as a public mail domain. The local workstation has no Exchange license or adequately sized server environment; it is not an Exchange deployment target.

See [Exchange supportability](https://learn.microsoft.com/en-us/exchange/plan-and-deploy/supportability-matrix), [system requirements](https://learn.microsoft.com/en-us/exchange/plan-and-deploy/system-requirements), and [Exchange 2016/2019 end of support](https://learn.microsoft.com/en-us/troubleshoot/exchange/administration/exchange-2019-2016-end-of-support).
